# 法源對照

**這份文件回答的問題**：這個專案的每一張憑證，對應到哪一條既有的法律或標準義務。

寫這份對照的過程改變了一項判準（招募費，見下），所以它不只是引用整理。

## 對照表

| 本專案的機制 | 法源 | 條文要點 |
|---|---|---|
| 工時憑證 | **勞動基準法第 30 條第 5、6 項** | 雇主應置備出勤紀錄並**保存 5 年**；應**逐日記載至分鐘**。違反第 5 項罰 9 萬～45 萬元；違反第 6 項罰 2 萬～30 萬元 |
| 工時憑證（RBA 判準） | **RBA Code of Conduct 8.0** | 每週不得超過 **60 小時含加班**（緊急或異常狀況除外）；**每七日至少一日休息**；**所有加班應為自願** |
| 工時憑證（台灣判準） | 勞動基準法第 32 條 | 月加班上限 46 小時——**與 RBA 的計算單位不同** |
| 招募費憑證（RBA 判準） | **RBA Code of Conduct 8.0** | **Employer Pays Principle**：勞工不得被要求支付招募費用；已支付者須償還，**最遲不得晚於就業開始後 90 天** |
| 招募費憑證（台灣判準） | 勞動部服務費上限 | 第一年每月 1,800 元、第二年 1,700、第三年 1,500 |
| 證件保管憑證 | **就業服務法第 57 條第 8 款** | 雇主不得非法扣留或侵占外國人之護照、居留證件或財物。罰 6 萬～30 萬元 |
| 證件保管憑證 | **護照條例第 32 條** | 非法扣留他人護照，足以生損害於公眾或他人者，**3 年以下有期徒刑**、拘役或併科 30 萬元以下罰金 |
| 薪資入帳憑證 | **勞動基準法第 22 條** | 工資應**全額直接給付**勞工；銀行轉帳符合直接給付 |

## 一項因為查證而改掉的判準

招募費憑證原本的公開欄位是 `feeWithinLegalCap`——依台灣服務費上限。查了 RBA Code 8.0 才發現**驗證方用的是完全不同的標準**：

| 標準 | 判準 | 通過條件 |
|---|---|---|
| 台灣法規 | 服務費有上限 | 未超過上限即合法 |
| RBA CoC 8.0 | Employer Pays | **勞工支付金額為零** |

**一間工廠可以完全符合台灣法規，同時完全違反 RBA。** 而套用 RBA 的品牌 Agent 拿到 `feeWithinLegalCap: true` 會讀成「合規」——那是**答錯題**，不是精確度不足。

現在兩套判準各自成為欄位，並由 `standardVersion` 標明版本。詳見 [`credentials.md`](credentials.md) 與 `employerPays.test.ts` 的 F1。

## 出勤紀錄：不是我們的假設，是勞檢最常抓到的違規之一

這一項值得單獨寫，因為它把本專案的問題敘述從「我們認為」變成「勞動檢查的統計」。

**全國違反勞基法條的排行中，出勤紀錄（第 30 條第 6 項）與工資給付方式（第 22 條）名列前茅。** 勞檢實務中常見的違規包括：

- 以「出勤自主管理」為由未置備出勤紀錄
- 僅以簽名方式記錄
- 未記載至分鐘，致**無法真實呈現勞工出勤狀況**

換句話說，「出勤紀錄不足以真實呈現工時」不是這個專案的前提假設，而是**主管機關最常開出的罰單類型之一**。

而法律**已經要求**逐日記載至分鐘並保存五年。這一點改變了整個專案的定位：

> **我們做的不是新增義務，是讓既有義務變成可驗證。**

## 這份對照沒有回答的兩個問題

**A. 打卡紀錄與實際工時是否系統性不符——部分解決。** 出勤紀錄違規是全國排行前列，勞檢常見的認定用語就是「無法真實呈現出勤狀況」。但**沒有查到量化研究**能說明落差的規模。

**B. 移工薪資走銀行轉帳與現金給付的實際比例——查無公開統計。**

B 對本專案有直接影響：交叉驗證假設薪資走銀行轉帳。**這個假設未經第一手驗證。** 若相當比例是現金給付，交叉驗證的適用範圍會比目前的敘述小。這一點在簡報中應該主動說明，而不是等人問。
