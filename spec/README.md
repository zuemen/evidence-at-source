## 怎麼檢查你的實作

```bash
npm run verify:external
```

這條指令用 [`packages/verifier`](../packages/verifier)——一個**零 `@eas/*` 相依**的獨立驗證器——跑 `vectors/` 裡的公開向量。

**你不需要相信我們的測試。** 同一組向量可以拿去驗任何人的實作，包括不是我們寫的。

## 這份規格現在還不是什麼

**它還不是一個標準，因為只有一個實作。**

一份規格要成為規格，需要至少第二個獨立實作跑過同一組向量並得到相同結果。在那之前，這裡的文件與向量是**一份邀請**，不是一個既成事實。

`packages/verifier` 是往那個方向走的第一步——它從規格重寫、不共用參考實作的程式碼，所以它與參考實作一致，代表規格說清楚了。但它仍然是我們寫的。

## 未來方向（本次未涵蓋）

| 項目 | 狀態 |
|---|---|
| **規格的版本治理** | 未定義。誰能修改、破壞性變更如何標示、舊版本如何淘汰——這些在有第二個實作之前不會有真正的答案，但需要在有之前就想好 |
